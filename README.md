# Coding Set

Small Python projects and course work from learning to code. Each section is a self-contained folder with a follow-along guide.

| Section | What you'll build | Folder |
| --- | --- | --- |
| WHOIS Lookup | A raw-socket WHOIS client that queries IANA on TCP port 43 | [01-whois-lookup](./01-whois-lookup) |
| Password Application Suite | A command-line password generator using `random` | [02-password-application-suite](./02-password-application-suite) |
| Python 100 Days of Code | Notes and beginner projects from days 1 to 8 of Angela Yu's Python bootcamp | [03-python-100-days-of-code](./03-python-100-days-of-code) |

## How to use

Open a section folder and follow its `README.md` from top to bottom. Every project uses Python 3 and the standard library only, so run the commands from inside that section's folder.
